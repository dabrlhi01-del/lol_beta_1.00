# LoL 관전 스탯 v2

## v2 변경점
1. 아이템 중복 제거
   - 소환사의 협곡(Map 11)
   - 실제 구매 가능
   - 동일 이름 중복 제거
2. 최근 12개 패치 선택 가능
   - Riot 사용자 표시는 26.16처럼 표시
   - 내부 Data Dragon 버전은 16.16.1처럼 유지
3. 챔피언 슬롯별 빌드 상태 분리
   - 레벨 / 아이템 6칸 / 룬 / 스킬 레벨을 각 슬롯마다 독립 저장
4. 스킬 설명
   - champion/<id>.json 상세 데이터 저장
5. 예상 스킬 피해
   - Data Dragon에서 기계적으로 읽을 수 있는 기본 피해와 계수가 있을 때만 추정
   - 첫 상대 챔피언의 방어력/마저를 적용한 참고 피해 표시

## 설치/업데이트
기존 GitHub 저장소의 파일을 이 ZIP 내용으로 교체한 뒤:
Actions → Update LoL patch catalog → Run workflow

성공하면 data/catalog.js가 커지고 최근 12개 패치가 들어갑니다.

## 피해 계산 주의
Data Dragon은 스킬 설명/효과 데이터를 제공하지만 모든 스킬의 전체 피해 공식이 구조화되어 있지는 않습니다.
다단히트, 잃은 체력 비례, 대상 최대 체력 비례, 변신, 스택, 강화 스킬 등은 별도 계산 엔진이 필요합니다.
따라서 v2의 피해량은 '기계 판독 가능한 항목만' 계산하는 보수적인 프로토타입입니다.


## v3 변경점
- 5개 슬롯 상단에 탑/정글/미드/원딜/서폿 역할 표시
- 슬롯 인덱스와 포지션 퀘스트 자동 연결
- 퀘스트 완료 토글
  - 탑: 레벨 상한 20
  - 정글: 정글/강가 이동속도 보조 수치 표시
  - 미드: 주요 2단계 장화의 3단계 장화 업그레이드 headline stat 반영
  - 원딜: 7번째 아이템 슬롯 개방
  - 서폿: 제어 와드 퀘스트 슬롯 효과 설명
- 팀별 드래곤 입력 UI
  - 화염: AD/AP
  - 대지: 방어력/MR
  - 마법공학: 공격속도/스킬가속
  - 구름: 비전투 이동속도/둔화저항
  - 바다: 잃은 체력 회복
  - 화공: 강인함/회복·보호막 효과
- 각 팀 최대 4개의 원소 드래곤 스택 입력
